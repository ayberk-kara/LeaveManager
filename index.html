Bu sayfa LeaveManager uygulamasını bilgisayarınıza kurmak içindir.

Kurulumu Başlat (setup.exe) Uygulama Manifesti (.application)

Notlar

  1. Windows bir uyarı gösterirse: More info → Run anyway.
  2. Uygulama verileri şurada tutulur: %LocalAppData%\LeaveManager\data.db
  3. Güncellemeler ClickOnce üzerinden otomatik alınır.
